Clear space

Keep clear on all four sides by the cap height of the “D” in “Dr.” Nothing sits inside that margin. Each file already carries about a third of it inside its own viewBox, so the logo never sits flush against its container even when placed carelessly.

Minimum widths were measured by rendering and reading, not by rule of thumb. Below them the descriptor’s letterspacing closes up and the tagline breaks into grey noise. Below a tagline form’s floor, drop to the form without a tagline rather than shrinking further.

The wordmark is set in the brand’s own faces — Gabarito for the name, Manrope for the descriptor and tagline — the same pairing the website uses, so the logo and the site speak in one voice.
