42 files in total — six lockup forms across six colourways, plus the symbol in the same six. Every letterform is outlined, so the artwork carries no font dependency and renders identically on a machine that has never seen Gabarito or Manrope.

The adaptive cells sit on a split ground on purpose. An adaptive SVG resolves against the viewer’s colour scheme, not the surface behind it, so referenced through an <img> it can land light-on-light. Inline it in the page — where data-theme reaches it — or pick the fixed -light / -dark file instead.
