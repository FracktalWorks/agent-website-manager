Accent colour belongs to the category, not the instance: mint for chronic conditions, apricot for aesthetics, lilac for trichology. A designer never picks the accent — the content type does.

Never set body copy in a pastel. Each accent carries a deep pair for text and a soft pair for fills; use them as a pair, never the base alone behind words.
